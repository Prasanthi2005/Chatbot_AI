# 🤖 AI Chatbot

A modern AI-powered chatbot built using **Python, Flask, Groq AI, HTML, CSS, and JavaScript**.

## ✨ Features

- 🤖 AI Chat with Groq
- 🎤 Voice Input
- 🔊 AI Voice Response
- 📝 Speech-to-Text
- 🔐 User Registration & Login
- 🔑 OTP Verification
- 🔄 Forgot & Reset Password
- 💬 Chat History
- 🖼️ Image Upload
- 📁 File Upload
- 🌓 Dark/Light Theme
- 👤 User Profile
- ⚙️ Settings
- 📄 Export Chat
- 📱 Responsive UI

## 🛠️ Technologies Used

- Python
- Flask
- Groq API
- HTML5
- CSS3
- JavaScript
- SQLite
- Bootstrap
